# Сайт государства — инструкция

Сайт показывает государство «вживую»: 3D-мир (крутится пальцем), смена дня и ночи по московскому времени,
таймер заседания Думы, паспорт, законы, жителей, министров, летопись и поиск «Найди себя: @ник».

## Как опубликовать (бесплатно)
1. Откройте https://app.netlify.com/drop и войдите (бесплатный аккаунт, иначе сайт удалится через час).
2. Перетащите в окно всю папку `site`.
3. Netlify даст адрес вида `что-то.netlify.app`. В настройках сайта (Site configuration → Change site name) задайте понятное имя.
4. Вставьте ссылку в шапку профиля Instagram.

## Как обновлять
Всё содержимое сайта — в одном файле `data.json`. После каждого заседания:
1. Отредактируйте `data.json` (или пришлите итоги Claude — он обновит файл).
2. В Netlify откройте сайт → вкладка **Deploys** → перетащите папку `site` ещё раз.
Открытые у зрителей страницы подхватят новые данные сами в течение минуты.

## Поля data.json
- `name` — название государства ("" — «Государство без имени»)
- `instagram` — ваш ник без @, например "gosudarstvo.100"
- `population` — число жителей (100 + новые подписчики)
- `stats` — текущие показатели 0–100: food (еда), money (казна), health (здоровье), order (порядок), happy (счастье).
  Ниже 20 — на сайте включается тревога «КРИЗИС» и дым над поселением; счастье от 70 — праздничная гирлянда.
- `world` — что построено в 3D: buildings ["storage","well","palisade","fields","pen"], cows, season ("summer"/"winter"), flag
- `session` — текущее заседание: num, question, format, deadline ("2026-11-09T19:00:00+03:00"), reel (ссылка на ролик),
  leaders (необязательно — лидеры голосования: [{"text":"…","author":"@ник","likes":64}]), leadersAt ("обновлено в 15:00")
- `laws` — принятые законы по порядку:
  {"num":2,"text":"…","author":"@ник","likes":187,"date":"10 ноября","roll":5,"effects":{"food":15,"money":-10},"building":"storage"}
  `building` — какую постройку закон добавил (на карте появится метка с автором), `veto: true` — закон отклонён,
  `kind: "name"` — закон о названии государства
- `startStats` — (необязательно) показатели на старте, для хроники законов
- `ministers` — министры: post, area, nick
- `residents` — граждане с паспортом: {"nick":"ник","num":1,"prof":"Скотовод","joined":"9 ноября"}
- `characters` — именные жители (портреты в папке img)
- `news` — летопись: {"date":"2026-11-09","text":"…"}

## Что умеет сайт
- Живой 3D-мир: день и ночь по Москве, огонь, дым, флаг, автооблёт камеры.
- Метки на объектах: у каждой постройки видно, по какому закону и чьему комментарию она появилась.
- Мир реагирует на показатели: кризис — тревога и дым, высокое счастье — гирлянда.
- «Сейчас»: идущее заседание, таймер, лидеры голосования и симулятор «Что будет, если…».
- «Законы»: хроника с состоянием государства после каждого решения.
- «Депутаты»: зал славы авторов принятых законов.
- «Паспорт»: поиск гражданина и картинка для сторис со снимком мира.
